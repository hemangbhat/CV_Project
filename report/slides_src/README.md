# Slide deck source

The presentation is published as a private Slides artifact:
https://claude.ai/artifact/3idxXEaK6STGwbYZHMBwvv (open it, then Share › Export to download
PowerPoint or PDF). This folder keeps its source: `project/deck.json` (slide order and sections)
and one HTML file per slide in `project/slides/`, with speaker notes in each slide's `<aside>`.
Images in the slides are the figures in `report/figures/` and `report/*.png`.

Order follows the department's research-presentation format and `report/RESEARCH_PRESENTATION.md`.
