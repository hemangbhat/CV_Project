3 · Applications in smart cities

Where a queue-measuring camera is useful

Adaptive junction control from existing traffic cameras, without cutting detector loops into the road.

Spillback monitoring: knowing when an approach is about to run out of storage, which in a network blocks the junction upstream.

Traffic analytics: queue lengths, stops per vehicle and approach demand for planning. This project's simulated demand shares come from the video counts.

Three uses. The middle one, spillback, is the one this project targets: a queue reaching the start of its road is what blocks upstream junctions in a network.
